# 0.16.0 优化记录

版本：0.16.0 / versionCode 89。基于 0.15.1，保留固定应用 ID 与签名，使用新的 Release 供应用内更新检测。

## 实现与验证范围

| 范围 | 实现 | 验证 |
| --- | --- | --- |
| 请求与认证 | 全进程同步 / 异步请求限流，当前播放预留名额；播放解析独立线程池；刷新互斥与账号修订检查 | MockWebServer 并发刷新、注销中刷新、队列取消、保留播放名额 |
| 推荐与兴趣 | 平滑有界抽样、全池标签轮换、正向标签分摊、独立证据置信度；系统筛选复用画像；屏蔽别名统一与撤销 | 高低权重比例、全池召回、重复证据去重、屏蔽同义词、既有长期画像测试 |
| 本地列表 | SQL 分页、搜索、时间排序；数据库收尾不阻塞主线程 | 超过 200 条收藏无遗漏 / 重复，关闭期间写入安全 |
| 预加载 | 当前流优先；后续流需连续缓存超过 40%、稳定播放、至少 15 秒缓冲、实测吞吐高于视频消耗；计量网络默认不开后续预加载；剩余存储低于 256 MiB 停止额外缓存 | 带宽 / 缓冲门槛与后续数量策略；弱网不关闭当前视频缓存 |
| 搜索 | AND 校验保留；优先较具体的种子；候选缓存、取消旧请求；可调整多语言词及仅原文模式；别名 TSV 资源 | 搜索字段、多关键词与内置别名回归，独立请求取消 |
| 弹幕 | 文本宽度缓存；只在播放且可见时跟随帧重绘；可调行数 | 既有方向、区域与生命周期回归 |
| 上传 | 前台服务、通知暂停、任务列表、加密草稿与上传完成检查点；账号变化中止；发布不确定保护 | 现有协议模拟服务、账号变更前拒绝发送、草稿序列化；不使用真实账号投稿 |
| 数据与隐私 | 可选账号兴趣库；导入导出白名单、大小及条目校验；历史 / 系统画像独立清理；不记录浏览开关；诊断脱敏 | 账号隔离 / 收藏共享、备份合并与非法数据回滚、旧分数导出边界、敏感链接脱敏 |
| 页面与恢复 | 共用日夜颜色、页面 / 上传职责拆分、主页有限会话恢复，不保存临时播放地址 | 状态恢复、跨页返回、深色页面截图与文字对比度检查 |
| 手势与引导 | 所有双连 2.5 秒；普通 / 竖屏按上下三段，横屏全屏按左右三段；普通引导与横屏全屏引导独立 | 2499 / 2500 毫秒边界、松手移动取消、先竖屏全屏再横屏全屏、控件手势与无障碍回归 |
| 小窗 | 纹理画面支持整体圆角裁剪；透明圆形触摸反馈；3 秒无操作隐藏；点击切换控件、拖动移动 | API 28 / 36 计时单测；设备悬浮窗显隐、控件、暂停 / 继续、关闭释放与截图 |

单元测试使用 Robolectric 与 MockWebServer。CI 在 Android 9 / 13 / 16（API 28 / 33 / 36）运行设备回归，每个平台覆盖界面返回与返回键两种路径，并保存截图。发布任务依赖所有平台通过；具体结果以对应提交的 GitHub Actions 报告为准。

## 性能观测

诊断页面记录本次进程最多 200 次首帧样本的 P50 / P95、最多 500 次播放中缓冲及总时长、媒体网络 / 缓存读取字节、Java 堆和进程 CPU 时间。指标不包含网址、视频 ID、标题或账号，不自动上传。

`scripts/capture-performance.sh` 可在相同设备、相同本地测试片段连续播放 60 秒后采集帧、内存与应用电量统计；结合本机诊断，在相同网络条件下比较版本。尚未完成真实手机上的公网弱网、耗电和长时间温升基准，不能把实现改动视作已测得的性能提升百分比。

已试构建 `:app:assembleRelease -PoptimizeRelease=true`：该开发快照由约 18.40 MB 降至约 4.44 MB，R8 构建成功。默认发布暂不启用混淆 / 资源收缩；启用前还需验证优化后的 APK 的网络、反射、资源别名及完整播放流程。该体积对比不是最终签名包大小承诺。

## 行为边界

- 网络不佳时仅取消下一条 / 后续预加载；当前播放继续尝试完整缓存。空间不足时回退在线播放，缓存不保证在视频播放完之前下载到 100%。
- 上传的二进制传输被打断后从文件开头重试；已经完整上传的文件可复用任务继续查询官网处理。没有经过核实的断点分片协议，因此不声称按字节续传。平台转码 / 审核和长时间后台执行仍受官网及 Android 限制。
- 发布结果未知时必须先查看我的作品确认，不自动重复发布。未用真实账号进行投稿测试。
- 按账号隔离只隔离系统兴趣、手动偏好、屏蔽与系统调整；收藏、浏览历史、设备推荐统计仍共享。原共享兴趣保留，可随时切回。
- 备份最多 5 MB，每表最多 20,000 条；只包含收藏与当前范围的兴趣，不包含登录密钥、历史、上传票据或媒体。合并保留已有条目；跨库写入不保证进程被强制终止时的整体原子性。
- 厂商权限管理、电池限制和真实网络行为需要对应设备验证。系统画中画由 Android 绘制；本版小窗样式改动针对应用悬浮窗。
