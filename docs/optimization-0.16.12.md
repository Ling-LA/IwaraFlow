## 边界与取舍

- 页面恢复使用有限快照，再继续联网分页，并非持久化所有搜索结果。长会话回看很早的视频可进入历史。
- 手动别名和 AI 都不能保证实体名必然正确；保留用户核对、编辑和禁用能力。服务端仍需接受相应搜索词。
- 默认共享历史 / 收藏，不自动猜测旧记录属于哪个账号。开启隔离后旧共享数据不丢失，关闭即可查看。
- 上传续传受官方协议约束：未上传完的文件从头传，完成的文件可继续查询处理状态。旧 token 任务在原凭据已丢失时不能安全推断归属。
- 容量上限针对已提交缓存片段；下载中的临时片段和索引会有小额开销。大于容量的视频不能完整常驻，但在线播放继续。
- 计量预算只约束提前缓存，正常播放不是流量上限。进程异常终止可能丢失最近不足 1 MiB 的尚未落盘计量，各并发传输可能有少量在途字节。
- Android 的系统剪贴板隐私提示由系统控制；手动粘贴 / 系统分享可替代自动读取。
- CI 的启动、内存和帧采样用于建立可比较基线，不宣称跨设备耗电或弱网性能提升百分比；真实手机的长时播放 / 发热仍需设备实测。
- lint 错误作为发布门槛，存量的文案国际化和弃用 API 等警告没有通过整体抑制掩盖。
