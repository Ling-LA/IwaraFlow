# 0.18.1 真机验证记录

状态：源码检查、独立 QA 包真机回归通过；正式签名包覆盖升级由发布构建后继续核验。

## 环境与方式

- Xiaomi 2410DPN6CC，Android 16 / API 36，1440×3200。
- 正式版保留账号及数据覆盖升级；自动化回归安装独立 `com.ling.iwaraflow.qa` 包，避免测试数据影响正式收藏与兴趣。
- 网络、真实解码、画面和生命周期使用实体设备执行。跨天场景调整保存快照的时间戳，分别模拟 7、30、90 天，再真正结束进程重启，不修改手机系统时间。

## 基线发现与修复

- 0.18.0 一次起播样本为 11.595 秒；Activity 启动 375 毫秒不等于首帧时间。观察到 `connection closed` 后只修改标题、缺少明确手动恢复入口，现增加独立重试按钮。
- 原推荐队列超过 12 小时即失效，丢弃仍存在的媒体缓存。改为检查连续缓存前缀/完整文件；完整文件只读取缓存，部分文件刷新凭据并核对内容身份后续传。
- 离开视频后未取消地址解析，弱网时会占据有限解析线程。补充请求取消、迟到回调隔离和恢复时重新加载。
- 真机发现退出横屏后短暂切到邻页。横竖屏布局变化期间锁定当前视频，忽略框架内部临时页面通知，避免误播放、误记历史与多余预加载。
- 0.18.0 的旧收藏迁移可能混入已有分类。改为独立新建迁移目标；不删除原列表条目，并保存逐条迁移检查点。

## 验证结果

- 单元测试 641 项通过，静态检查 0 错误（仍有弃用 API 等既有警告）。
- 22 项实体设备用例全部通过，覆盖卡片/竖滑、横屏和返回、设置/后台暂停保持、小窗、资料页、收藏迁移/选择/新建/取消、网络与缓存。收藏用例修正了预加载邻页按钮定位后单独重跑通过，其他 21 项通过整套运行。
- 收藏回归实际长按当前视频星标打开管理，并验证短按将同一视频从两个官方协议测试列表移除；其他视频保留，返回列表与封面同步刷新。部分删除失败、读回失败、账号切换及迁移不补回主动取消项另有单元回归。
- 真实解码网络用例通过：提前缓存后播放不再请求媒体；延迟响应期间暂停，网络恢复后仍保持暂停，手动播放可恢复。播放和预加载流量分别核验。
- 首轮真实官网预缓存恢复日志记录复用 2 条，当前首帧样本 166 毫秒。这是单次缓存命中样本，不代表所有视频或网络的起播速度。
- 7、30、90 天快照均已分别执行保存、结束进程、恢复并实际播放；过期完整媒体不发起网络读取。部分缓存测试核对重读字节与只补缺失数据。
- 正式签名升级与真实官网迁移结果在发布构建后补充，不以本地测试接口代替官网验收。

## 限制

- 本次抽样验证不能保证所有机型、视频与运营商网络永不出现异常。
- 跨天测试验证时间与凭据过期逻辑及真实磁盘复用，不等同于实际等待 90 天；系统清理、缓存容量淘汰或用户删除后的数据无法恢复。
- 官方网络接口耗时不由客户端完全控制；缓存命中和实际首帧数据分别记录，不以应用启动时间替代播放延迟。
