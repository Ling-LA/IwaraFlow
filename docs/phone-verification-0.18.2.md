## 本地检查

- 681 项单元测试全部通过，0 失败、0 跳过；静态检查 0 错误。仍有既有 API 弃用等警告。
- 收藏夹改名保留 ID；删除只清理该夹归属，其他夹副本保留；移动先确认目标副本再移除来源，部分失败可安全重试。
- 已主动移除或删除的旧收藏不会被迁移补回；改名后的默认夹继续按原 ID 使用。
- 切换账号后，旧管理弹窗、迟到回调和旧收藏夹页面不能继续创建、修改或混入新账号状态。

- 全屏横竖屏、播放/暂停、单击切换控件、小窗和视图回收场景下，点赞数量与评论入口随播放控件一起显隐。
