# Iwara 官方播放列表收藏夹

2026-11-01 核实官网当前公开客户端 3.3.7：

- [主客户端](https://www.iwara.tv/main.838884031a28ff0e346d.js)：`fetchPlaylists`、`fetchPlaylist`、`createPlaylist`、`addToPlaylist`、`removeFromPlaylist`、`fetchLightContent`。
- [视频收藏夹选择器](https://www.iwara.tv/chunk-2517.051116c1f15511657730.js)：通过 `light/playlists?id=视频编号` 读取每个播放列表的 `added`；创建表单仅含 `title`。
- [播放列表详情](https://www.iwara.tv/chunk-9203.8e069a6817468d9f3890.js)：详情使用 `playlist` 与分页的 `results/count/limit/page`。
- [播放列表编辑表单](https://www.iwara.tv/chunk-5565.dbad64f90421d5ebfefa.js)：仅标题字段，未提供私密开关。

## 协议

| 操作 | 请求 |
| --- | --- |
| 自己的收藏夹目录 | `GET /playlists?user={accountId}&page=0&limit=50` |
| 视频归属 | `GET /light/playlists?id={videoId}`，数组每条含 `id/title/added` |
| 收藏夹视频 | `GET /playlist/{playlistId}?page=0&limit=50` |
| 创建收藏夹 | `POST /playlists`，JSON `{ "title": "名称" }` |
| 添加视频 | `POST /playlist/{playlistId}/{videoId}`，空请求体 |
| 移除视频 | `DELETE /playlist/{playlistId}/{videoId}` |

请求使用现有登录会话，`X-Site: www.iwara.tv`，无需重新网页登录。官方 `/favorites/videos` 是点赞列表，不能充当收藏夹。

目录与详情响应通过官网实时只读接口核对；写操作依据官方客户端代码，并以 MockWebServer 验证，没有向真实账号添加测试视频或收藏夹。

## 本地行为

- 收藏夹数据按账号隔离缓存；打开目录、打开收藏夹和激活视频时同步。视频归属轻量查询去重，短期复用缓存。
- 点击未收藏的视频加入记住的收藏夹、默认收藏夹或首个已有收藏夹；全部为空才创建默认收藏夹。短按已收藏星标会先读取官方归属，逐个移出该视频所属的收藏夹并复核结果；仅长按星标打开管理选择器。双连对已收藏视频不会额外复制到其他夹。
- 取消过程中部分失败会保留尚未确认移除的收藏状态，重试先重新读取归属，避免重复操作；主动取消的旧收藏记录为迁移检查点，原本地档案保留，但自动续传不会重新加入。
- 写操作成功后才更新本地星标。创建请求不会自动重试或携带凭证跳转；结果不明确时提示先刷新确认。
- 选择多夹先添加后移除，部分失败保留已成功结果，刷新归属后可重试。变更账号后的迟到响应不应用到新账号。
- 缓存允许网络异常时离线阅读；官方明确返回无权限、未找到等错误时不回退旧内容。
- 升级后的旧版本地收藏自动逐条同步到**单独新建的默认公开收藏夹**，绝不占用现有分类、最近使用或同名默认收藏夹。同名时新夹加“旧版收藏”及必要的序号区分，后续只凭已确认的官方 ID 续传。
- 0.18.0 已迁移至原分类夹的用户会补同步到新的专用默认夹，原分类内所有内容保持不变。旧记录仅表示“已处理”，无法证明当时是否新增，不用于自动删除原分类中的视频。旧记录已处理且如今不在原目标的条目视为后续移除，不重新加回；新迁移完成后的条目同样不重复添加。
- 创建前保存标题与当时全部官方 ID。结果不明时仅通过只读查询恢复唯一新增 ID，自动流程不会重发创建请求；查不到或出现多个同名新夹时暂停并明确提示。明确的 4xx 拒绝可稍后重试，网络中断或 5xx 等不确定情况只有用户核对后通过“重试同步”才能再次创建。
- 每条官网确认后持久记录新增、已存在或尊重移除的结果；失败和重启可续传，原始本地记录始终保留。用户删除专用默认夹后不自动重建或改用其他分类夹。
- 共享本地收藏的自动迁移绑定首次升级时的登录账号，避免切换账号后再次自动公开另一份旧收藏；账号隔离库按已验证账号独立读取，其他账号可使用明确的“重试同步/导入”入口。部分迁移的目标收藏夹固定，后续切换快捷收藏目标不影响续传。
- 收藏夹为官方公开播放列表，创建及选择页面均说明公开属性。

## 验证边界

接口、缓存、失败状态、账户隔离与迁移续传使用模拟接口回归。真实账号权限、官网限流和未来协议变动仍取决于官方服务；自动迁移失败会保留原始收藏和进度，不伪报完成。
