# 0.17.1 推荐贴合度与高赞权重调整

## 问题与处理

| 问题 | 调整 |
| --- | --- |
| 多数候选已有较高的来源、热度基础分，原抽样曲线进入平缓区，个人兴趣的分差被压小 | 每批分数减去中位数后再进行有界加权抽样；共同基础分不影响相对排序概率 |
| 画像对最终排序影响偏弱，热门视频与普通视频的差距也不明显 | 画像系数从 0.38 提升到 0.9；点赞量的对数系数从 0.5 提升到 0.95，质量总分最高 14；保留平滑点赞率和新鲜度 |
| 长期使用后，通用标签与具体偏好容易同时达到分值上限 | 按不同视频的标签出现比例校准系统正分；通用标签至少保留 35%，少量或久远证据影响较小；正负方向各自保留最强信号，其余标签递减计分 |
| 兴趣来源只取最新的前两页；看完后容易只剩全站榜单候选 | 兴趣标签同时取高赞、近期两个排序；补充轮继续查兴趣标签和作者的后续作品 |
| 全站未看候选足够时不再补充兴趣来源 | 兴趣候选大多已看时，利用首轮剩余预算额外补充一轮；不额外延长首轮等待上限 |
| 前面的慢请求耗尽预算后，后面已完成的请求也被丢弃 | 优先读取已完成结果；仅对仍未完成的请求应用截止时间，并取消未完成任务 |

## 保留的约束

- 继续使用现有本地长期画像，无数据库迁移，不要求重新积累兴趣。
- 同一视频的观看、点赞、收藏及重播不重复计算曝光次数；搜索与云端点赞种子不作为本地曝光分母。
- 通用标签校准不修改长期存储分，不减弱负反馈，不改变手动偏好和明确屏蔽的含义。
- 抽样权重比保持有界，未屏蔽内容保留非零概率；作者打散、内容多样性、关注比例、经典穿插和手动兴趣连续数量限制继续有效。
- 个性化来源空结果或失败时，不因“兴趣候选不足”增加额外一轮等待。

## 回归范围

- 模拟长期观看与点赞记录，验证具体兴趣高于常见通用标签，系统比例调整与手动兴趣仍有效。
- 200 个固定随机种子、等量候选、装配后的前 20 条：分别验证兴趣命中与兴趣内高赞内容占比明显高于随机均分，同时保留其他候选机会。
- 验证强兴趣能超过不相关的高热度，极高热度不能绕过主动屏蔽，多标签不能填满兴趣分上限，强正向标签不会冲淡强负反馈。
- 模拟已看完兴趣前几页、全站仍有足够未看视频，验证能够补充未看的兴趣视频。
- 模拟慢来源、空来源与慢补充请求，验证已完成结果保留、空来源不多等、可选补充共享首轮截止时间。
