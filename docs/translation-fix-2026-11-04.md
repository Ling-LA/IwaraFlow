# 0.18.3 翻译、分享与网络提示验证记录（2026-11-04）

## 原因

翻译结果原先只检查是否与原文相同、是否包含足够比例的汉字。AI 在第二次尝试中复述中文重试说明时，会通过这项检查并进入评论、简介、弹幕共用的内存缓存。拉长拼写的短评论在失败后仍按同样的文本重试，容易再次得到未翻译的结果；本地语言判断也缺少常见印尼口语信号。

完整回归还发现启动配置的异步读取可能迟于显式设置：旧读取完成后会覆盖新选择。现在启动读取先记录配置代次，返回时核对；只要用户已选择配置（包含再次选择同一配置），旧读取就不会写回。

## 改动

- AI 请求将待译正文放在单独的 `text` 字段，要求返回 `source_language` 与 `translation`，明确区分正文、口语理解要求及系统指令；不增加服务商专属参数，仍兼容原来的语言行、普通文本及代码围栏格式。
- 拦截返回的内部操作指令、无效 JSON、纯标点或表情等无效结果。失败时保留原文并允许手动重试，自动修复仍最多一次，不自动转发到其他服务商。
- 自动重试时，仅对整条短评论中已知的英语感叹词作拉长拼写规范化，例如 `niiiice`；用户名、链接、普通词和专名不作全局压缩，显示原文与缓存键仍保持原样。
- 增加印尼口语识别，纠正明确印尼语正文被泛化标为英语的情况，保留服务商识别出的马来语及未知语言标签。
- 读取缓存时重新校验，并将配置变更、清理和写回放在同一锁内，避免旧请求在切换服务后重新写入缓存。

## 同批分享与网络提示改动

- 视频与作者分享文案均附带 `https://github.com/Ling-LA/IwaraFlow/releases/latest` 下载入口；原视频或作者链接仍排在前面，粘贴回搜索框时继续打开原内容。
- 设置的“关于”页加入两条独立标注的网络服务推广链接，分别保留用户提供的 `aff=pPRUgU8c` 和 `code=EgAG` 参数。
- 主页每次遇到明确的连接失败时，在原错误说明下加入这两条可点击链接，不再限定首次安装。链接只响应用户点击，不自动打开浏览器。无结果、取消、登录权限及 HTTP 服务端错误不附推广链接，后续普通提示会清理旧链接状态。
- 推荐加载失败保留底层异常类型，每轮重新记录错误，避免把服务器回复中的 `timeout` 字样或上一轮故障误当作本轮连接故障；请求整体等待超时也会显示链接。

链接测试检查应用发出的跳转目标，没有访问或验证推广服务商的可用性。
