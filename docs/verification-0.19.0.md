## 预缓存与进程结束

- 7 / 30 / 90 天前保存的完整缓存仍可恢复。
- 过期链接的部分缓存会刷新凭据，并只获取缺失字节；完整缓存不重复请求媒体数据。
- 另外独立执行 `prepare`、强制结束 QA 进程、`restore` 两阶段，设置保存时间为 90 天前。两阶段均 `OK (1 test)`；恢复阶段验证进程 ID 已改变，真实解码并播放保存队列的首条视频，媒体上游请求次数为 0。
- 损坏快照、缓存被回收、已看/屏蔽、隐私与账号变化等分支正常回退。

这里的天数通过保存时间偏移模拟，不代表连续等待了 90 天；也不承诺系统或用户清除后的缓存可以恢复。

## 性能采样及边界

- 同一真机对 256 个中性候选计算推荐分数：首次约 527.6 ms，复用文字特征缓存后约 39.0 ms。批量排序在后台线程执行；这是一次采样，不是所有设备的时延上限。
- 中性长按动画场景采集 1042 帧，帧耗时 P95 约 3.96 ms；复用动画启动调用中位数约 0.011 ms。原测试 JSON 的说明沿用 “emulator fixture” 字样，本次实际运行设备是上述手机。该指标不是线上视频播放的端到端帧率或网络流畅度承诺。
- 规则测试验证的是学习、限幅与排序行为，不能直接证明个人满意度。未知名称、列表未提供简介、实际网络抖动仍可能影响推荐和加载体验。
