## 更新内容

- 正式发布切换为私密 RSA-4096 签名密钥，私钥与口令存于 GitHub Actions 加密 Secrets，不再使用仓库中公开的开发密钥签出正式安装包。
- 使用 Android APK v3 签名轮换证明衔接旧版，保留覆盖升级和应用数据；升级后拒绝旧开发签名替换新版。发布前在 Android 9、13、16 验证升级、数据保留、重装及旧签名拒绝。
- 发布流程增加签名证书校验与独立升级检查，全部通过后才发布；更新说明随版本维护，应用内检查更新可直接查看。包含 0.16.9 的跨页面点赞同步修复。

### 升级说明

推荐使用应用内「检查更新」或下载本页的 `IwaraFlow-signed.apk` 直接覆盖安装，无需卸载。支持从旧开发签名迁移到新发布签名。请勿安装第三方重新签名的 APK。

旧开发签名历史上曾公开。本次只为后续正式版本使用私密签名，无法让已经公开的旧密钥重新保密。
