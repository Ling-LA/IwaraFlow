## 更新内容

- 修复首次打开时推荐偶发加载失败：兴趣标签的随机排序改为先固定抽样分数，再排序，避免排序比较前后不一致引发异常；保留按兴趣权重抽样及屏蔽规则。
- 「检查更新」和「关于」统一移到设置页的「应用信息」，主页及其他播放页的浮窗菜单不再重复显示。
- 保留启动自动检查更新；设置页可以查看更新说明、下载安装包和打开 GitHub 项目地址。退出设置时释放更新检查资源，避免延迟结果继续弹窗。

### 升级说明

继续使用私密发布签名，可从 0.16.10 或更早的正式版本直接覆盖升级，无需卸载。旧版本可通过原菜单中的「检查更新」安装，新版本入口位于「设置 → 应用信息 → 检查更新」。
