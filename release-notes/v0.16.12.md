# IwaraFlow 0.16.12

本次集中处理客户端稳定性、搜索响应、本地数据与资源占用，继续使用 0.16.10 起的私密发布签名。

- 收藏保存失败会回滚并提示；历史、兴趣和备份导入增加写入失败检查。
- 搜索结果先展示、后台限时验证，切换查询取消旧请求；保持列表阅读位置和播放进度。可保存自定义匹配别名，多关键词仍按 AND 匹配。
- 搜索、作者、历史及收藏页面恢复播放位置和暂停状态；长列表回收过早条目，下载记录改为完整分页、搜索和排序。
- 弱负反馈按时间衰减，多标签内容分摊学习增量；兴趣与历史 / 收藏可分别按账号隔离，原共享数据保留。
- 关闭评论面板取消未完成翻译，拖动和循环播放重新对齐弹幕；设置取消不再保存部分开关，无效代理阻止保存。
- 菜单新增手动粘贴链接，也可从系统分享文本或 Iwara HTTPS 链接进入。
- 缓存增加容量和每日移动网络预加载预算，相同视频文件的刷新签名链接可复用缓存。网络不佳只停止后续预加载，预算耗尽不影响正常在线播放。
- 上传任务按已验证账号 ID 识别，同账号重新登录后可继续；未传完文件仍需从头上传。
- 正式包启用 R8 / 资源压缩。发布流程加入 lint、实际压缩包启动及性能采样检查，并继续验证 Android 28 / 33 / 36 导航和签名升级。

开启账号隔离不会自动搬移共享记录；关闭隔离即可查看原共享数据。备份只包含当前范围的收藏与兴趣，不含登录凭据、浏览历史或上传凭据。

验证详情见仓库 docs/optimization-0.16.12.md。模拟器检查用于发现回归，不能代替各品牌真机的耗电和弱网测试。
