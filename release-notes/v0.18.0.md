# IwaraFlow 0.18.0

- 最新、流行、人气改为双列卡片浏览；点击后仍可上下滑动连续播放，返回恢复列表位置。推荐页保持原样。
- 收藏夹接入 Iwara 官方播放列表，支持新建、选择多个收藏夹、封面预览与本地缓存同步。长按星标选择收藏夹，短按快速收藏；长按点赞或播放画面中间仍可双连。
- 升级后自动同步旧版本地收藏；没有播放列表时创建默认播放列表，已有播放列表优先使用默认或第一个。逐条去重、失败续传并保留本地旧记录。**Iwara 官方播放列表为公开内容。**
- 已点赞的视频再次双击可获得一次小额本地偏好加分；每视频、每账号仅一次，不重复增加官网点赞数。
- 全屏新增评论入口、点赞数量；横屏评论采用侧边面板。浏览历史增加“仅显示已点赞视频”筛选。
- 节日期间适度增加相应标签的推荐机会，节后自动退回常规权重，屏蔽与多样性约束保持有效。
- 优化兴趣作者召回及正负反馈聚合，修复强正标签压过负标签、总分限幅削弱视频“不感兴趣”的情况。

沿用现有私密发布签名与签名轮换链，可从上一正式版直接覆盖升级。

发布流程会检查 Android 9、13、16 的页面与播放回归，以及正式签名覆盖升级、保留数据和拒绝旧签名替换；全部通过后才开放下载。
