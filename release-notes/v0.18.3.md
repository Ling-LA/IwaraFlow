# IwaraFlow 0.18.3

- **翻译结果修复**：避免把 AI 内部重试说明显示为评论或简介译文；无效结果保留原文并支持重试，不写入翻译缓存。
- **口语与语言识别改进**：改善印尼语口语标签和拉长拼写短评论的重试，保留用户名、链接及原文，自动修复最多一次。
- **翻译配置保持最新选择**：修复启动时后台读取的旧配置覆盖新选择的问题；切换服务后阻止旧请求重新填入缓存。
- **分享附带软件下载**：视频、作者分享文案加入 IwaraFlow 官方下载入口，原内容链接继续保留，粘贴回搜索框仍能直达对应视频或作者。
- **网络服务推广入口**：“关于”页提供两条可点击推广链接；首页每次遇到网络连接错误时也会显示，不限首次安装，仅在点击后跳转。
- **错误提示区分原因**：整体请求超时也能显示网络帮助；登录权限、HTTP 服务器错误、取消和空结果不附推广链接，不沿用上一轮推荐故障。

本地及 CI 的 709 项单元测试通过，Android Lint 无错误；Android 9、13、16 页面回归、跨进程预缓存恢复及签名覆盖升级检查全部通过。另在本地 Android 16 模拟器复核页面返回播放。本次未连接实体设备，未进行真机复测。

沿用正式私密 RSA-4096 发布签名，可覆盖升级并保留应用数据。详情见[本次验证记录](https://github.com/Ling-LA/IwaraFlow/blob/main/docs/translation-fix-2026-11-04.md)。
