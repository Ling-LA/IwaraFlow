# IwaraFlow 0.18.4

- **画面长按三连**：中间区域按住 1.5 秒完成点赞、收藏和关注作者；已完成的操作不取消，提前松手或移动取消手势。
- **更小的透明动画**：采用新的单个三指手势矢量图标，保留顺时针进度圈，移除原来的大背景板。横竖屏引导同步更新。
- **改善长按反馈流畅度**：进度圈按屏幕帧刷新；点赞、收藏 GIF 在后台准备并复用，减少主线程解码和重复刷新；快速点击不会出现长按圆环。
- **同步与失败处理**：三连只补齐未完成的操作，关注失败时保留已成功的点赞和收藏并提示；避免关注自己、重复关注及切换账号后旧回调修改新状态。
- 长按点赞按钮仍为点赞＋收藏；短按点赞、短按收藏和长按收藏夹管理规则不变。

沿用正式私密 RSA-4096 发布签名，可覆盖升级并保留应用数据。[验证记录](https://github.com/Ling-LA/IwaraFlow/blob/main/docs/triple-reaction-0.18.4.md)。
