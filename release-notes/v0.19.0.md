# IwaraFlow 0.19.0

- 推荐加入标题和已获取简介的关键词信号，过滤推广与模板文字，合并已知多语言名称；跨视频、跨作者积累证据，并限制单条行为与文字权重。旧历史标题可参与，无需额外抓取详情或调用 AI。
- 节日结束后清理自动节日偏好、召回来源与缓存理由；手动兴趣设置保留。
- 修复列表末尾播放结束后的控件切换与重播；关闭“点一下画面暂停播放”后，结束状态也能单击切换信息栏和进度条。
- 设置新增中文（默认）、英语、日语、韩语界面切换。简介、评论和弹幕的翻译目标仍为简体中文。
- 直接分享至 X / Telegram 附视频缩略图或作者简介卡片（头像、名称、账号、简介摘要、主页地址）；头像失败仍生成卡片，无法准备图片时回退文字。移除分享文案中的软件下载链接。
- 优化多语言搜索：保留已知完整名称，严格区分其他关键词和别名；未知短名称不再轻率直译，AI 校对保留已核实别名。

推荐模型为本地关键词分析，不读取视频画面，也不保证每条推荐都符合个人偏好。已有官方账号、点赞及收藏夹数据继续保留。
